Pioneer's gateway exposes a **JSON-RPC 2.0** API over WebSocket. All clients (the desktop app, CLI, or any custom client) communicate with the gateway using this protocol.

## Transport

Connect to the gateway at:

```
ws://localhost:17878/ws
```

(or the port you configured)

## Authentication

All requests must include a JWT Bearer token in the WebSocket handshake or as a protocol-level field. Generate a token with:

```bash
pioneer issue-superuser-token
```

## Conventions

**Request format:**
```json
{
  "jsonrpc": "2.0",
  "id": "unique-request-id",
  "method": "threads.create",
  "params": { ... }
}
```

**Response format:**
```json
{
  "jsonrpc": "2.0",
  "id": "unique-request-id",
  "result": { ... }
}
```

**Notifications** (server → client, no id):
```json
{
  "jsonrpc": "2.0",
  "method": "turn.event",
  "params": { ... }
}
```
