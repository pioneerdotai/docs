## What is Pioneer?

Pioneer is a **local-first AI platform** that runs entirely on your machine. It brings together a persistent gateway service, a native desktop app, and a rich set of tools so you can build a personal AI workspace without sending your data to a third-party cloud.

## How it works

Pioneer has three main components that work together:

<Steps>
  <Step title="Gateway">
    A long-running Rust service that owns all state — conversations, tasks, skills, MCP servers, provider configuration. Clients connect to it over a local WebSocket JSON-RPC channel.
  </Step>
  <Step title="Desktop App">
    A native app (built with GPUI) that gives you a full UI for managing threads, configuring providers, installing skills, and browsing task history.
  </Step>
  <Step title="Agent Loop">
    When you send a message, the gateway runs an agent loop that talks to your chosen LLM, orchestrates tool calls, and streams results back to the desktop in real time.
  </Step>
</Steps>
