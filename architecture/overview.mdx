Pioneer is a Rust workspace of 16 crates organized around a clear separation of concerns: a persistent **gateway** service owns all state and execution, while a **desktop app** is just a thin client that connects to it.

## High-level diagram

```
┌─────────────────────────────────────────────┐
│              Desktop App (GPUI)             │
│   Sidebar │ Timeline │ Composer │ Settings  │
└──────────────────┬──────────────────────────┘
                   │ WebSocket JSON-RPC
┌──────────────────▼──────────────────────────┐
│                  Gateway                    │
│  Transport │ Auth │ Workspaces │ Sessions   │
│  ┌──────────────────────────────────────┐   │
│  │           Agent Loop                │   │
│  │  Prompt → LLM Provider → Tool Calls │   │
│  └──────────────────────────────────────┘   │
│  Tasks │ Skills │ MCP │ SQLite DB           │
└─────────────────────────────────────────────┘
```

## Design principles

**Protocol-first.** All contracts are defined as JSON-RPC types in the `protocol` crate, with JSON schemas auto-generated. Clients never depend on internal implementation details.

**Event sourcing.** Agent execution emits durable events that are persisted before being acted on. This enables recovery after crashes and interruptions.

**Local-first.** Everything runs on your machine. The gateway is a self-contained process with no required external dependencies beyond an LLM provider.

**Repository pattern.** All database access goes through a clean CRUD layer; nothing in the business logic touches SeaORM directly.
